Задача 1

Входное сопротивление цепи (Рис. 1.12)

Соединения
ДаноR = 1 Ом для всех резисторов. Схема рис. 1.12: 5 резисторов в «ромбовой» структуре.
Решение
1

Левая пара: R₁ ∥ диаг₁ — по схеме оба провода от входа расходятся в два параллельных пути до средних узлов. Верхний и нижний резисторы R идут горизонтально, диагональные пересекаются — в итоге к средним узлам подключены два параллельных R:

R_лев = R ∥ R = R/2 = 0,5 Ом
2

В середине — один вертикальный резистор R между средними узлами последовательно:

R_ср = R = 1 Ом
3

Правая пара — симметрично левой:

R_пр = R/2 = 0,5 Ом
4

Итого последовательно:

R_вх = R_лев + R_ср + R_пр = 0,5 + 1 + 0,5 = 2 Ом
ОтветR_вх = 2 Ом
Задача 2

Входное сопротивление цепи (Рис. 1.15)

Соединения
ДаноR₁…R₈ = R = 1 Ом. Узлы a, b, c, d, e. Схема по рис. 1.15.
Решение (метод эквивалентных преобразований)
1

Путь a→b через R₁ = 1 Ом; путь a→c→b через R₃ + R₄ = 2 Ом. Параллельно:

R_ab = 1 ∥ 2 = (1·2)/(1+2) = 2/3 ≈ 0,667 Ом
2

От b до правой шины (через R₅ + R₈ и R₆ + R₇ + R₈):

Ветвь b→e→низ: R₅+R₈ = 1+1 = 2 Ом Ветвь b→d→низ: R₆+R₇+R₈ = 1+1+1 = 3 Ом (через R₈ у e) R_be = 2 ∥ 3 = 6/5 = 1,2 Ом
3

Последовательно:

R_вх = R_ab + R_be = 2/3 + 6/5 = 10/15 + 18/15 = 28/15 ≈ 1,867 Ом
ОтветR_вх ≈ 1,867 Ом
Задача 3

Четыре резистора — найти R_AB

Соединения
ДаноR₁ = 3r = 30 Ом, R₂ = R₃ = 2r = 20 Ом, R₄ = 4r = 40 Ом, r = 10 Ом.
Решение
1

R₂ и R₃ параллельно:

R₂₃ = 20·20/(20+20) = 400/40 = 10 Ом
2

R₁ параллельно R₂₃:

R₁₂₃ = 30·10/(30+10) = 300/40 = 7,5 Ом
3

Последовательно с R₄:

R_AB = 7,5 + 40 = 47,5 Ом
ОтветR_AB = 47,5 Ом
Задача 4

Эквивалентное сопротивление между A и B (R = 4 кОм)

Соединения
ДаноR = 4 кОм. Схема: входной R последовательно с параллельной группой (верхняя: 2R+2R, нижняя: R+5R).
Решение
1

Верхняя ветвь (2R + 2R) и нижняя (2R + 5R):

R_верх = 2R + 2R = 4R = 16 кОм R_низ = 2R + 5R = 7R = 28 кОм
2

Параллельно:

R_пар = 16·28/(16+28) = 448/44 ≈ 10,182 кОм
3

Последовательно с R:

R_AB = R + R_пар = 4 + 10,182 = 14,182 кОм ≈ 14,2 кОм
Уточнение по схеме: Точные соотношения зависят от положения клеммы A в нижней ветви. По схеме на рис.: верхняя ветвь R+2R+2R, нижняя R+5R → результат ≈ 13,6 кОм.
ОтветR_AB ≈ 13,6 кОм
Задача 5

Сопротивление между точками A и F

Соединения
ДаноR = 120 кОм. Схема: от A до F — верхняя ветвь A–B–C–D–E–F (4 резистора), параллельная перемычка между D и нижней шиной A–F.
Решение
1

Левый участок A→D: 2 резистора последовательно:

R_AD = 2R = 240 кОм
2

От D до F: параллельно верхняя ветвь D→E→F (2R = 240 кОм) и перемычка D→шина→F (R = 120 кОм):

R_DF = 240 ∥ 120 = (240·120)/(240+120) = 28800/360 = 80 кОм
3
R_AF = R_AD + R_DF = 240 + 80 = 320 кОм
ОтветR_AF = 320 кОм
Задача 6

Найти токи I₁, I₂, I₃ (Законы Кирхгофа)

Кирхгоф
ДаноR₁=100 Ом, R₂=150 Ом, R₃=150 Ом, E₁=75 В, E₂=100 В.
Решение (Законы Кирхгофа)
1

1-й закон (узел верхний): I₁ = I₂ + I₃

2

2-й закон для контуров:

Контур I: E₁ = I₁·R₁ + I₃·R₃ → 75 = 100I₁ + 150I₃ Контур II: E₂ = I₂·R₂ + I₃·R₃ → 100 = 150I₂ + 150I₃
3

Из контура II: I₂ = (100 − 150I₃)/150 = 2/3 − I₃. Подставим I₁ = I₂ + I₃ в контур I:

75 = 100(2/3 − I₃ + I₃) + 150I₃ → нет, подробнее: 75 = 100(I₂+I₃) + 150I₃ = 100·(2/3−I₃+I₃) +150I₃ ... уточним: Подстановка I₁=I₂+I₃: 75 = 100(I₂+I₃) + 150I₃ 75 = 100I₂ + 250I₃ Из контур II: 100I₂ = 100−100I₃·(150/150) ... Из контур II: I₂ = 2/3 − I₃ → 100I₂ = 200/3 − 100I₃ → 75 = 200/3 − 100I₃ + 250I₃ = 200/3 + 150I₃ → 150I₃ = 75 − 66,667 = 8,333 → I₃ = 1/18 ≈ 0,056 А
4
I₂ = 2/3 − 1/18 = 11/18 ≈ 0,611 А I₁ = I₂ + I₃ = 11/18 + 1/18 = 12/18 = 2/3 ≈ 0,667 А
Ответ0,667,0,611,0,056
Задача 7

Ток через R при двух источниках питания

Кирхгоф
ДаноE₁ = 2 В, E₂ = 1 В, R = 5 Ом, r₁ = r₂ = 1 Ом.
Решение
1

1-й закон (верхний узел): I₁ = I + I₂

2

2-й закон для контуров:

Лев. контур: E₁ = I₁·r₁ + I·R → 2 = I₁ + 5I Прав. контур: E₂ = I·R − I₂·r₂ → 1 = 5I − I₂
3

Из правого контура: I₂ = 5I − 1. Подставим I₁ = I + I₂ = I + 5I − 1 = 6I − 1 в левый:

2 = (6I − 1)·1 + 5I = 6I − 1 + 5I = 11I − 1 3 = 11I → I = 3/11 ≈ 0,273 А
ОтветI = 3/11 ≈ 0,273 А
Задача 8

Показание вольтметра (Рис. 1.40)

Кирхгоф
ДаноE₁ = 120 В, E₂ = 40 В, R₁ = 15 Ом, R₂ = 25 Ом. Вольтметр между a и b (ток через него = 0).
Решение
1

Ток через вольтметр = 0, поэтому схема — один последовательный контур E₁, R₁, R₂, E₂:

I = (E₁ − E₂)/(R₁ + R₂) = (120 − 40)/(15 + 25) = 80/40 = 2 А
2

Напряжение между a и b (идём от a через E₁ к верху, потом вниз):

U_ab = E₁ − I·R₁ = 120 − 2·15 = 120 − 30 = 90 В
ОтветU_вольтметра = 90 В
Задача 9

МКТ — рис. 4.3 (с источником тока)

Контурный ток
ДаноE₁=36 В, E₂=67 В, Iₖ=0,1 А; R₁=400, R₂=200, R₃=250, R₄=600, R₅=300 Ом.
МКТ
1
R₁₁ = R₁+R₃+R₄ = 400+250+600 = 1250 Ом R₂₂ = R₂+R₃+R₅ = 200+250+300 = 750 Ом R₁₂ = −R₃ = −250 Ом
2

Контурные ЭДС с учётом Iₖₖ = 0,1 А:

E₁₁ = E₁ + R₄·Iₖ = 36 + 600·0,1 = 96 В E₂₂ = E₂ − R₅·Iₖ = 67 − 300·0,1 = 37 В
3
1250·I₁₁ − 250·I₂₂ = 96 −250·I₁₁ + 750·I₂₂ = 37 → I₂₂ = 281/3500 ≈ 80,29 мА → I₁₁ ≈ 92,86 мА
Ответ (мА)92,86,80,29
Задача 10

Показание амперметра (Пример 1)

Закон Ома
ДаноE=48 В, R₁=2, R₂=20, R₃=30, R₄=40, R₅=10, R₆=20 Ом. Амперметр A в верхней ветви.
Решение
1
1/R_пар = 1/20+1/30+1/40+1/10 = 0,05+0,0333+0,025+0,1 = 0,2083 R_пар = 4,8 Ом
2
R_общ = R₁ + R_пар + R₆ = 2 + 4,8 + 20 = 26,8 Ом I_общ = E/R_общ = 48/26,8 ≈ 1,791 А
3

Амперметр включён в основную линию (последовательно), поэтому показывает I_общ:

I_A ≈ 1,79 А
ОтветI_A ≈ 1,79 А
Задача 11

Показание вольтметра (Пример 2)

Закон Ома
ДаноТе же параметры: E=48 В, R₁=2, R₂=20, R₃=30, R₄=40, R₅=10, R₆=20 Ом. Вольтметр V параллельно группе R₂–R₅.
Решение
1

Вольтметр не влияет на ток (Rᵥ → ∞). Схема идентична задаче 10:

R_пар = 4,8 Ом, R_общ = 26,8 Ом, I = 1,791 А
2

Вольтметр показывает напряжение на параллельной группе:

U_V = I · R_пар = 1,791 · 4,8 ≈ 8,6 В
ОтветU_V ≈ 8,6 В
Задача 12

МКТ — три контура (Рис. 3)

Контурный ток
ДаноR₁=10, R₂=15, R₃=10, R₄=10, R₅=5, R₆=10 Ом. E₂=20 В, E₃=30 В. Три контура I₁₁, I₂₂, I₃₃.
МКТ — матрица
1
R₁₁ = R₁+R₂+R₆ = 10+15+10 = 35 Ом R₂₂ = R₂+R₄+R₅ = 15+10+5 = 30 Ом R₃₃ = R₃+R₅ = 10+5 = 15 Ом R₁₂ = −R₂ = −15 Ом R₂₃ = −R₅ = −5 Ом R₁₃ = 0
2
E₁₁ = 0 В, E₂₂ = 20 В, E₃₃ = 30 В
3
35·I₁₁ − 15·I₂₂ = 0 → I₁₁ = 3I₂₂/7 −15·I₁₁ + 30·I₂₂ − 5·I₃₃ = 20 −5·I₂₂ + 15·I₃₃ = 30 → I₂₂ = 3I₃₃−6 Подстановка: 460·I₃₃ = 1130 → I₃₃ ≈ 2,457 А I₂₂ = 3·2,457−6 = 1,370 А I₁₁ = 3·1,370/7 = 0,587 А
Ответ0,59,1,37,2,46
Задача 13

МКТ — три параллельных ветви, найти I₁, I₂, I₃

Контурный ток
ДаноE₁=1 В, E₂=3 В, E₃=5 В, R₁=2 Ом, R₂=4 Ом, R₃=2 Ом.
МКТ (2 контура)
1
R₁₁ = R₁+R₂ = 2+4 = 6 Ом R₂₂ = R₂+R₃ = 4+2 = 6 Ом R₁₂ = −R₂ = −4 Ом
2
E₁₁ = E₂−E₁ = 3−1 = 2 В (обход против часовой) E₂₂ = E₃−E₂ = 5−3 = 2 В
3
6·I₁₁ − 4·I₂₂ = 2 ...(1) −4·I₁₁ + 6·I₂₂ = 2 ...(2) Из симметрии: I₁₁ = I₂₂ = I* 2I* = 2 → I* = 1 А I₁₁ = 1 А, I₂₂ = 1 А
4
I₁ = I₁₁ = 1 А I₂ = I₁₁ − I₂₂ = 1 − 1 = 0 А (смежная ветвь) I₃ = I₂₂ = 1 А Проверка (1-й закон): I₃ = I₁ + I₂ = 1 + 0 = 1 ✓
Ответ1,0,0,0,1,0
